CodeTabs 0.17.1 · Windows x64 便携版

启动：解压到可写目录，双击 CodeTabs.exe。要求 Windows 10/11 x64 和 .NET Framework 4.8。
程序未签名。发布 ZIP 的 SHA-256 校验文件随下载提供。

“全部接入 VS Code”批量接入窗口；菜单可选择其他应用。
顶部按钮均为图标，悬停查看说明；叠放窗口带减号可移出全部 VS Code，不关闭应用。
软盘打开组合列表并输入名称存入当前所有应用窗口及标签顺序；回转箭头打开列表选择恢复或删除。
支持保存多个组合，选择时预览窗口顺序。删除组合不关闭窗口。旧版单个组合会自动导入。
恢复需要应用窗口已打开；无法唯一识别的窗口会提示，其他已有标签保留在末尾。
组合配置保存在 config/window-layouts.json，包含窗口标题，分享时请勿附带。
标签字号跟随显示器 DPI；标签多时优先压缩短标题留白，空间不足时可滚轮横向浏览。
点击标签切换，右键打开操作菜单。Win+Alt+鼠标左/右键或滚轮也可切换。
标签向外箭头移出并恢复接入前的位置和尺寸；× 正常请求关闭目标应用。
拖动标题栏到标签栏接入，或使用“拖拽接入”按钮；Esc 取消。

VS Code 默认使用输入法兼容模式，隐藏已接入窗口的任务栏及 Alt+Tab 入口，移出或正常退出后恢复。菜单可切回原嵌入方式，重新接入后生效。
正常关闭 CodeTabs 会等待窗口恢复；请不要强制结束。显示器布局变化时可能调整位置以保持可见。

Codex 总览只读本地可访问的会话与索引，支持项目/对话检索、隐藏、置顶和完成提醒。
卡片默认采用紧凑布局。顶部 − / 百分比 / ＋ 调节 60%–150% 缩放，默认 90%；点击百分比选择档位。
支持 Ctrl+加号/减号，Ctrl+0 恢复默认；各显示器分别记忆缩放，不影响已接入应用。
状态不等于任务质量验收；打开项目不会自动开始任务，也不保证切换到指定对话。

个人配置保存在程序旁的 config 文件夹，可能包含项目路径、会话关联及自定义标题。
升级时保留 config；分享源码或发布包时不要附带该文件夹。
