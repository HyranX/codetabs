CodeTabs 0.17.2
Windows 10/11 x64 · 正式版 · 未签名

本版改进：
- 点击项目卡片“打开”或双击卡片时，除打开项目目录，还会请求对应窗口的 Codex 扩展显示该卡片的历史对话。
- 支持切换已接入窗口、接入已打开项目和新建项目窗口。
- 使用对话 ID 和精确窗口编号路由，核对 VS Code 主进程与窗口标题；目标有歧义时提示，不猜测窗口。
- 不发送提示词，不开始任务，不修改对话内容；没有可识别对话 ID 的目录卡片仍只打开项目。

要求：目标窗口已安装并登录 Codex 扩展。已在 26.1021.22027 扩展验证指定历史对话显示；首次链接可能需要 VS Code 确认。独立用户数据目录、多实例无法安全定位时会提示。远程对话跳转尚未实际验证。

验证：新增对话标识、URI、精确窗口、歧义拒绝及主进程校验回归；保留完整桌面与卡片缩放回归。CI 执行非 UI 检查。
升级：正常关闭旧版，替换程序并保留 config 文件夹。
包内仅含 CodeTabs.exe、README.txt、RELEASE-NOTES.txt、LICENSE、NOTICE 和 SHA256SUMS.txt。
