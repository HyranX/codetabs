CodeTabs 0.16.10-preview
Windows 10/11 x64 · 便携预览版 · 未签名

本版改进：
- 已接入窗口从任务栏及 Alt+Tab 隐藏，只保留 CodeTabs 入口；移出或正常退出时恢复。
- 保留独立输入队列，接入/移出之外不执行额外隐藏重显。
- 点击 VS Code 时，CodeTabs 标签栏所在容器同步跟随到其正下方，修复两个窗口被其他应用隔开的情况。
- 调整层级时保留 VS Code 前台输入焦点；不重新引入输入队列关联。
- 修复接入后只有容器空白底色：根据实际可见性和层级校正，不再仅依赖缓存。
- 被动校正只放回容器上方，不激活 VS Code，不盖过已经位于上方的其他应用。
- 修复右键标签时菜单失效及窗口闪烁；菜单打开时不再隐藏/重显 VS Code。
- 容器移动事件立即同步兼容窗口，减少拖动跟随延迟。
- 修正非置顶窗口的前后顺序，避免移动后被容器遮挡、看起来内容空白。
- 整理公开源码，添加 Apache-2.0 许可证、隐私检查及自动 Release 流程。

保留功能：输入法兼容模式、多屏混合 DPI 的像素尺寸恢复、退出等待恢复、Codex 总览与完成提醒。

验证：本机独立测试进程覆盖右键菜单、内容可见性、窗口层级、停用轮询后的移动同步，以及三屏 150%/100% 缩放下的恢复。真实第三方应用仍需试用确认。CI 模式仅执行非 UI 检查，不能替代桌面回归。

升级：正常关闭旧版，替换程序，保留 config 文件夹。不要将个人 config、会话日志或项目路径上传到公开仓库。

包内仅含 CodeTabs.exe、README.txt、RELEASE-NOTES.txt、LICENSE、NOTICE 和 SHA256SUMS.txt。
