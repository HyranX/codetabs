CodeTabs 0.17.1
Windows 10/11 x64 · 正式版 · 未签名

本版改进：
- Codex 项目卡片更紧凑：减少内部间距、限制自动拉伸宽度，长路径单行省略，悬停查看完整内容。
- 新增 − / 百分比 / ＋ 缩放控件，可选 60%–150%，默认 90%。文字、卡片与操作区域同步缩放。
- 各显示器分别记忆缩放，换屏自动恢复；调整时保留当前选择与浏览位置。
- 支持 Ctrl+加号/减号调节，Ctrl+0 恢复默认。

验证：覆盖各缩放档位的文字/按钮布局、命中区域、百分比菜单、设置持久化及跨屏恢复；保留完整窗口、组合列表与通知回归。CI 执行非 UI 检查。

升级：正常关闭旧版，替换程序并保留 config 文件夹。缩放设置保存在 config/overview-settings.json。
已知限制：组合恢复需要应用窗口已打开；特殊第三方窗口仍可能存在兼容差异，崩溃恢复守护尚未实现。
包内仅含 CodeTabs.exe、README.txt、RELEASE-NOTES.txt、LICENSE、NOTICE 和 SHA256SUMS.txt。
