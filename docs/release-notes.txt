CodeTabs 0.17.0
Windows 10/11 x64 · 正式版 · 未签名

本版改进：
- 窗口组合列表：可保存多个命名组合，预览窗口顺序，选择任意组合恢复或删除。
- 保存所有已接入应用、从左到右的标签顺序和当前标签；删除组合不会关闭应用窗口。
- 旧版单个组合自动导入列表，删除后不会重复导入。
- 字号跟随所在显示器 DPI：100% 为 13 像素，150% 为 19.5 像素，标签栏高度随字体调整。
- 标签多时优先压缩短标题的留白，再压缩长标题；保留按钮和最小宽度，超出时滚轮横向浏览。
- 保留紧凑图标工具栏、一键移出全部 VS Code、多屏窗口恢复和 Codex 总览。

使用：软盘图标打开列表并输入名称存入当前组合；回转箭头打开列表，选择组合后恢复或删除。配置位于 config/window-layouts.json。

验证：本机打包覆盖启动、完整窗口回归、通知、组合持久化与迁移、列表保存/预览/恢复/删除及多屏字号；CI 执行非 UI 检查。

已知限制：恢复组合需要应用窗口已打开，不自动启动应用或恢复文档。缺失或无法唯一识别的窗口会提示；已有其他标签保留在末尾。特殊弹窗、自绘窗口等第三方应用仍可能存在兼容差异；程序崩溃后的自动恢复守护尚未实现。

升级：正常关闭旧版，替换程序并保留 config 文件夹。个人配置包含窗口标题和项目路径，请勿上传公开仓库。
包内仅含 CodeTabs.exe、README.txt、RELEASE-NOTES.txt、LICENSE、NOTICE 和 SHA256SUMS.txt。
